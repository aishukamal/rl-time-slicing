That's the whole step. The snapshot agent is already on every GPU node (DaemonSet from step 1); the taint just keeps non-cooperative pods off the shared pool.
STEP 3 — ONE SHARED CLAIM PER GPU POOL · standard Kubernetes DRA
This is the sharing trick: every job's trainer pod references the same trainers claim, every sampler pod the same samplers claim — instead of asking for their own nvidia.com/gpu. Kubernetes packs them onto the shared GPUs; the orchestrator arbitrates turns per pool.
